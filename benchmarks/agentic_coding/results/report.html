How it was tested.

The tasks

20 Python tasks: 14 build from a written spec, 6 fix bugs in existing code (multi-file, concurrency, dates). 203 hidden unittest cases, all passed by a reference solution first.

The agents

opencode run with the user's normal config, thinking on, one fresh workspace per task. Eight agents ran at a time because each opencode process needs about 600 MB of RAM.

The measurements

A local proxy timed every request. TTFT runs from request sent to first streamed token (reasoning, text or tool call), so it includes queueing and prefill.

The server

vLLM on spark-ba51 through the :8080 gateway. This is not the Q6 GGUF with Q8 KV cache that produced the poor results, so quantization effects are not covered.

Integrity

No agent read the hidden tests or reference solutions. All 491 tool calls stayed inside each agent's own workspace.

Scope

Self-contained, well-specified tasks. Large codebases with vague tickets are harder and were not tested.
